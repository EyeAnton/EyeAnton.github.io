Сверяйся с этой картой и правь точечно (Grep → Edit). Не перечитывай файлы целиком без нужды.

## Ручные инструменты (вместо работы Claude)
- Превью ссылки: правка текста в `tools/og.html` → `powershell -File tools/og.ps1` → `assets/og.jpg`.
- Обложка проекта со скриншота сайта: `powershell -File tools/shot.ps1 -Url <адрес> -Name <id>` → `assets/shots/<id>.jpg`.
- Превью CV для «гостя»: после замены PDF → `python tools/cv_thumbs.py` (нужен `pip install pymupdf`).
- Проверка без входа: `python -m http.server 8000` → http://localhost:8000/admin.html?local (публикация отключена).

## Решения пользователя
- Позиционирование: Anton Egorov, AI Creative Technologist; «в первую очередь дизайнер» — кнопки «Код» скрыты.
- Нельзя: звёздочки ✦ (выдают Claude), сетка на фоне, грязные размытые градиенты, анимация подарков на обложке.
- Блоки: свои (с `type`) удаляются ✕ (есть «Вернуть»), встроенные блоки главной — только скрываются. «+ блок» под блоком вставляет новый после него. На странице проекта блок бывает «половина» (`w: "half"`) — два в ряд, при удалении сетка смыкается. Пустой перевод на сайте подменяется другим языком. Внутри своих блоков любой текст удаляется по наведению «✕ текст» (ключ убирается из блока целиком, RU и EN), текст пункта списка — ещё и «✕ пункт» (карточка, шаг, кнопка); есть «Вернуть». Встроенные тексты главной не удаляются.
- Картинки блоков грузятся в `assets/shots/` при публикации; неиспользуемые загрузки удаляются сами.
- Emotions Club живёт в `projects.json` (перенесён из репо emotions-club, PR #16), картинки и видео — по ссылкам `/emotions-club/assets/…` из того репо. Старая страница `/emotions-club/` пока работает, но на неё никто не ссылается; правки кейса — только через админку.
- Переносы строк в текстах — `\n` в site.json (`white-space: pre-line`), в редакторе Shift+Enter.
