Изменения сохраняются в GitHub-репозиторий сайта. После «Опубликовать» сайт обновится примерно через минуту.

Доступ только для владельца сайта.

Последний шаг настройки — один раз сохранить GitHub-токен. Дальше он подтягивается сам после входа через Google, на любом устройстве.

  1. Откройте создание токена на GitHub (Fine-grained token).
  2. Repository access → Only select repositories → EyeAnton.github.io.
  3. Permissions → Repository → Contents: Read and write.
